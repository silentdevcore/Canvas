# Code-Migrations-UI — Feature Checklist

## Overview

A "Migrations" page in the Canvas web app that lets developers paste code written for another PDF library, convert it to Canvas.Pdf C# code, and preview the resulting PDF — all in the browser.

---

## User Flow

1. Developer opens the Canvas web app and clicks **Migrations** in the toolbar.
2. A full-screen overlay opens.
3. Developer selects the source PDF framework (e.g. Syncfusion PDF) from a dropdown.
4. Developer pastes their existing code into the **Source Code** textarea.
5. Developer clicks **Convert** → the right panel shows the equivalent **Canvas.Pdf** C# code, plus a diagnostics bar listing any issues.
6. Developer clicks **Generate Preview** → an iframe renders the actual PDF produced by the converted code.
7. Developer copies or downloads the canvas code with the **Copy** / **Download .cs** buttons.

## Backend API

Base path: `Canvas.WebApi/Controllers/MigrationController.cs`

### `GET /api/migration/frameworks`

Returns metadata for all supported frameworks.

```json
[
  { "id": "Syncfusion", "name": "Syncfusion PDF", "status": "full",
    "description": "Full pattern-based conversion with coordinate adapter" },
  { "id": "Apryse", "name": "Apryse (PDFTron)", "status": "skeleton",
    "description": "Basic document/page/save mapping" }
]
```

### `POST /api/migration/convert`

```json
// Request
{ "framework": "Syncfusion", "sourceCode": "..." }

// Response
{
  "canvasCode": "using Canvas.Pdf;\n...",
  "summary": {
    "convertedCount": 4,
    "warningCount": 1,
    "errorCount": 0,
    "totalDiagnostics": 5
  },
  "diagnostics": [
    { "code": "CANMIGSYNC001", "severity": "Info", "message": "DrawString converted to DrawTextFromTop" },
    { "code": "CANMIGSYNC010", "severity": "Warning", "message": "PdfGrid (table) has no direct Canvas equivalent — manual rewrite required" }
  ]
}
```

### `POST /api/migration/preview`

Same request body as `/convert`. Returns `application/pdf` bytes generated by executing the converted Canvas code.

## Conversion Mapping — Syncfusion PDF (Full)

| Syncfusion pattern | Canvas.Pdf equivalent |
|---|---|
| `using Syncfusion.Pdf;` | `using Canvas.Pdf;` |
| `using Syncfusion.Pdf.Graphics;` | *(removed)* |
| `new PdfDocument()` | `new PdfDocument()` |
| `document.Pages.Add()` | `document.AddPage()` |
| `page.Graphics.DrawString(text, font, brush, x, y)` | `page.DrawTextFromTop(text, x, y, fontSize)` |
| `page.Graphics.DrawLine(pen, x1, y1, x2, y2)` | `page.DrawLineFromTop(x1, y1, x2, y2, lineWidth, color)` |
| `page.Graphics.DrawRectangle(pen, x, y, w, h)` | `page.DrawRectangleFromTop(x, y, w, h, strokeColor)` |
| `page.Graphics.DrawImage(img, x, y, w, h)` | `page.DrawImageFromTop(stream, x, y, w, h)` |
| `document.Save(path)` | `document.Save(path)` |
| `document.Save(stream)` | `document.Save(stream)` |

**Coordinate system:** Syncfusion uses top-left origin (Y down). Canvas uses bottom-left (Y up).
`DrawTextFromTop` / `DrawLineFromTop` / etc. perform the conversion: `canvasY = pageHeight - syncfusionY - elementHeight`.

**Diagnostics emitted:**

| Code | Severity | Trigger |
|------|----------|---------|
| `CANMIGSYNC001` | Info | DrawString → DrawTextFromTop |
| `CANMIGSYNC002` | Info | DrawLine → DrawLineFromTop |
| `CANMIGSYNC003` | Info | DrawRectangle → DrawRectangleFromTop |
| `CANMIGSYNC004` | Info | DrawImage → DrawImageFromTop |
| `CANMIGSYNC010` | Warning | PdfGrid detected — no direct equivalent |
| `CANMIGSYNC011` | Warning | PdfTextWebLink detected — use `page.AddWebLink()` |
| `CANMIGSYNC012` | Warning | document.Security detected — not supported |

## Conversion Mapping — Other Frameworks (Skeleton)

Each skeleton converter returns a Canvas.Pdf "Hello World" code string based on documented mappings, plus a placeholder one-page PDF preview with the framework name.

| Framework | Key mapping note |
|-----------|-----------------|
| Apryse | `new PDFDoc()` → `new PdfDocument()`; `doc.PageCreate()` + `doc.PagePushBack()` → `document.AddPage()` |
| Aspose | Roslyn-backed pilot: `new Document()` → `new PdfDocument()`; `document.Pages.Add()` → `document.AddPage()`; simple `TextFragment`/`TextBuilder` flows supported |
| DsPdf | `new GcPdfDocument()` → `new PdfDocument()`; `page.Graphics.DrawString(...)` → `page.DrawText(...)` |
| Spire | `new PdfDocument()` → alias; `page.Canvas.DrawString(...)` → `page.DrawText(...)` |
| GemBox | `document.Pages.Add()` → `document.AddPage()` |
| iText7 | Roslyn-backed pilot: `new PdfWriter + PdfDocument + Document` → `new PdfDocument()`; `doc.Add(new Paragraph)` → `page.DrawTextFromTop(...)`; simple `ShowTextAligned` and `PdfCanvas` shapes/text supported |
| IronPDF | HTML-to-PDF: out of scope for v1; returns informational note |
| ActivePDF | API not yet confirmed; returns placeholder |
| LEADTOOLS | Raster/OCR pipelines out of scope; returns informational note |
| PDFKit.NET | API identity unconfirmed; returns placeholder |
| Foxit | `new PDFDoc()` → `new PdfDocument()` |
| DevExpress | Processor vs. generator APIs TBD; returns placeholder |
