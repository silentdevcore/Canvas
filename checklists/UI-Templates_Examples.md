# UI-Templates Examples Checklist

## Scope
Concrete example variations to implement for each template category in the UI Designer gallery.
Each checkbox = one distinct template variation ready to design and add to the gallery.

---

- [x] **Freelancer Invoice** — minimal single-page layout, hourly line items, bank transfer details, no logo
