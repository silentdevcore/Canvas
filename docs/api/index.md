# API Reference

Generated from the XML documentation comments on the public `Canvas.Pdf` and `Canvas.Core.Contracts` types.

Start with:

- [`PdfDocument`](xref:Canvas.Pdf.PdfDocument) — create a document, add pages, export bytes.
- [`PdfPage`](xref:Canvas.Pdf.PdfPage) — draw text, shapes, images, tables, links, and form fields.
- [`PdfColor`](xref:Canvas.Pdf.PdfColor) / `PdfGrayColor` / `PdfCmykColor` — color models.
- [`DesignExportDto`](xref:Canvas.Core.Contracts.DesignExportDto) — the declarative design model used by
  the visual designer and the export/render endpoints.
